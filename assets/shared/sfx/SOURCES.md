# Recorded sounds: sources and licences

Candidates for chai's juice (CHAI-92, SH-226), heard on `lab/juice.html`; none is in a game yet. Each file is cut, trimmed,
high-passed at 160 Hz, made mono and set soft by `build/tools/juice/make_sfx.py` (a hit peaks at -16 dBFS; a pour or simmer
sits near -32 dBFS RMS, peak -12 dBFS; the family's clips run near -21 dBFS RMS), then encoded as 64 kbit/s mp3. Fetched 6 Nov 2026.

**Licences.** CC0 (Kenney, BigSoundBank): public domain, any use, no credit needed. **Mixkit Sound Effects Free Licence**
(Envato): free for commercial and personal projects, no attribution; an item may not be resold or made available on its own
(as a stand-alone file or in a sound pack). Inside the app that is fine; the open repository and the web build serve the file
itself, so before the app stores either keep the Mixkit ones out of a public repo, or prefer the CC0 option where Zafar likes it
as much (decision in `build/reports/juice-lab-2026-11-06.md`).
