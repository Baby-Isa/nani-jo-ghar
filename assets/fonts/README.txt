The game's own fonts (6 Nov 2026, SH-224): the one place every page takes them from. css/shared/fonts.css is the only file that
names these files; the type tokens in css/shared/tokens.css are the only place that names the faces. Latin subsets of the variable
fonts, from Fontsource (@fontsource-variable).

  lora.woff2, lora-italic.woff2   Lora, weights 400-700, upright and italic. Copyright 2011 The Lora Project Authors
                                  (https://github.com/cyrealtype/Lora-Cyrillic), with Reserved Font Name "Lora".
  nunito-sans.woff2               Nunito Sans, weights 200-1000, upright. Copyright 2016 The Nunito Sans Project Authors
                                  (https://github.com/Fonthausen/NunitoSans).
