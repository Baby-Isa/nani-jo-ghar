# Fun patterns: a pool to draw upon

Codified from the clinic's game research (`docs/archive/feedback/clinic-playtest-2026-09-29.md`, `2026-10-01.md`, `docs/process/mode-design-method.md` §2). Pick patterns; the Kutchi must still decide the challenge (leak test, non-negotiable 4). Each is the upside version: nothing floods, breaks or punishes.

| Pattern | What it is | Where it lives now / example |
|---|---|---|
| Time pressure, friendly | A visible timer that makes a round brisk; ~15% quicker per level, set in data; running out never loses what you earned | Cook stations; the tooth's careful drilling (keep the good, drill the bad) |
| Variety | Consecutive errands never repeat the same main action; a stage is a pool of variants | Clinic heal games (one comic game per body part) |
| Reveal / delight | A comic reaction, a satisfying sound, a near miss, a transformation | Knee bandage wrap, hic, boing |
| Careful precision | Drag or tap carefully over a target while avoiding the good part | Tooth drill, stitches, plaster placement |
| Matching by rule | Different colours healed by different things; the mapping is taught first | Tongue bumps and drinks (colour to drink) |
| Sequencing | Do the steps in order; rows tick as each closes | Cook recipes, first/then (pela, ne poi) |
| Counting along | Nani counts as the child works (L1), then less | Number words in every station |
| Collecting from a belt | Grab the asked-for items as they pass | Pharmacy conveyor |
| Closed-set speaking | Say a word after the recorded model with pills as fallback | Conversations, speaking ramp (E32) |
| Pool of things to draw upon | A big library per stage, scored 1-5 on fun, Kutchi, build cost; keep the best 8-10 | Clinic healing library |

Rules of thumb: borrow the mechanic, never the theme; research current kids' apps (Toca Boca, Sago Mini, Dr. Panda, Pok Pok, Khan Academy Kids) before inventing; if a pattern teaches no word and is not fun on its own, cut it (H48).
