# Nani jo Ghar

A game that teaches young children Kutchi through play at Nani's house, voiced only by the real family. It runs as a web app on GitHub Pages (this repository's `main` branch is the live site) and will be wrapped for the app stores.

- **Play it:** open `index.html` (Nani's house), or `labs.html` for every lab page.
- **Working on it:** start with [`CLAUDE.md`](CLAUDE.md), then [`docs/status.md`](docs/status.md) and the index of every doc, [`docs/README.md`](docs/README.md).
- **How the code is laid out:** [`docs/architecture/code-map.md`](docs/architecture/code-map.md).
- **Tests and checks:** [`docs/architecture/testing.md`](docs/architecture/testing.md) and the QA checklist, [`docs/process/qa-checklist.md`](docs/process/qa-checklist.md).

The previous README (the 23–24 Sept fruit-bowl and Cook proof-of-concept notes) is kept at `docs/archive/root-README-2026-09-30.md`.
