# Count to a heard number

**Designed; Sprint 10.** Cook's count generalised (`cook.md`): any thing into any container, as many as Nani says. Used by many stages (`docs/game-design/days/`): eggs into the basket, cobs onto the grill, shells into the bucket, fried peas into cones, and the pay game (coins onto the counter for a heard price).

## Rules

- **The number is only heard:** never written before the answer; coins carry no digits.
- Levels: L1 one to three; L2 to five, and "a little / more / enough"; L3 two counts in one line ("two, and then one"); pay L3 adds change.
- A miscount is shown, not judged: the count stays on screen and the book shows it; it can be taken back until Done.
