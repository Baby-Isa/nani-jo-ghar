# Put it in its place

**Designed; Sprint 10.** One engine on the core, from Tidy up's place engine (`tidy-up.md`): tap a thing, then tap where it goes (or drag it there). Used by many stages (`docs/game-design/days/`): feed the animals, animals home, the picnic cloth, put the shopping away, the thing for Ali, set the table.

## Rules

- **The word picks:** every thing could go to more than one place (hens and goats both want food; both animals have a home), so only the Kutchi decides.
- Levels: L1 one thing, the place named; L2 a count ("two scoops for the hen"); L3 positions (behind, next to, in, on) and owners (Nana's cup).
- A wrong place slides back and Nani says the line again; no verdict; it can be taken back until Done.
