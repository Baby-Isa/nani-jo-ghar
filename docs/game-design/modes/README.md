# Modes: one line each

Each mode has one file in this folder (parked modes keep a short stub pointing to their full design in `docs/archive/modes/`). The core verb is what the child does again and again; it is what makes the mode different from the others. Cook is the flagship (`cook.md`); the clinic and Find it are the focus modes; the rest are parked and move onto the shared core when their turn comes (decision 38; the order of work is rule H41). The live state of every mode is `docs/status.md`; the open feedback is `docs/process/regressions.md`.
