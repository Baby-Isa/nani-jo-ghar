# Decisions log

This is the running history of Zafar's decisions: date, decision, why, link. It replaces the scattered "Zafar's answers" sections in older docs.
Standing rules live in `docs/process/rules.md`; this log holds the history, plus decisions too specific to be rules (a station's layout, a word choice, a clinic game design).
The newest word from Zafar wins. If a newer decision clashes with an older one here, strike the old one through and point to the new one.
When a decision changes a standing rule, update `docs/process/rules.md` in the same commit.
To add one: append a single line at the end of the right date's section (new date = new `##` section), in the form `- **Topic:** decision. *Why:* reason. Source: path § heading. Rule: ID`.
**Superseded** means a later decision or rule replaced it. It stays here, struck through, with a pointer to what replaced it; never delete it.
Things Claude assumed but Zafar or Mum never confirmed are not decisions. They are listed in the last section until someone confirms them.
Source paths are the original docs (some will have moved to `docs/archive/`); rule IDs (A1, H13 and so on) are those in `docs/process/rules.md`.
