# Game ideas: to be built (TBC)

Zafar has approved these ideas, but no build has them yet. They're parked here so they don't get lost.

**The rule (Zafar, 26 Sept):** before any mode or station is called finished, the orchestrator reminds Zafar of every open idea for it here, and they decide together whether it goes in. Zafar may also ask for them at any time. When an idea is built, mark it done with its commit or branch; don't delete it.
